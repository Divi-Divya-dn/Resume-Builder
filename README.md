# Resume-Builder

A simple and user-friendly Resume Builder web application that helps users create a professional resume by entering their personal, educational, career, and skill information.

📌 Project Overview

The Resume Builder is designed to make resume creation easier for students, freshers, and job seekers.

Users can enter their information through a simple form, and the application organizes the information into a structured resume.

The project is developed using HTML, CSS, and JavaScript and is designed to be extended with additional features such as PDF generation, resume templates, and Android application support.

✨ Features

- 📝 Career Objective
- 👤 Personal Details
- 🎓 Educational Details
- 💼 Employment History
- 💻 Technical Skills
- 🤝 Soft Skills
- 📚 Other Details
- 📊 Education details displayed in table format
- 📄 Structured resume preview
- 📱 Responsive user interface
- 🎨 Simple and clean design
- 🔄 Easy to edit entered information

🛠️ Technologies Used

- HTML5 – Structure of the application
- CSS3 – Styling and responsive design
- JavaScript – Form handling and dynamic resume generation

🚀 How to Run the Project

Method 1 – Using a Browser

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Enter your resume information.
5. Generate and view your resume.

Method 2 – Using VS Code

1. Open the project folder in Visual Studio Code.
2. Open "index.html".
3. Install the Live Server extension if required.
4. Right-click "index.html".
5. Select Open with Live Server.
6. The Resume Builder will open in your browser.

🧾 Resume Sections

The application can contain the following sections:

Career Objective

Users can provide their career objective or professional summary.

Personal Details

- Full Name
- Email
- Phone Number
- Address
- Date of Birth
- Gender

Educational Details

Educational information can be entered in a structured table containing:

Qualification| Institution| Year| Percentage
School| School Name| Year| Percentage
PUC| College Name| Year| Percentage
Degree| University College| Year| Percentage

Employment History

Users can enter their previous work experience, internship, or employment details.

Technical Skills

Examples:

- Python
- HTML
- CSS
- JavaScript
- SQL
- Git & GitHub

Soft Skills

Examples:

- Communication
- Teamwork
- Leadership
- Problem Solving
- Time Management

Other Details

Additional information can be included according to the user's requirements.
